# 🥟 Dame Samoussa - Funnel de Vente VIP

Site web de vente en ligne pour Dame Samoussa, spécialiste des snacks africains premium pour événements.

## 🌟 Fonctionnalités

- **Landing Page** : Présentation du Pack VIP anniversaire
- **Upsell** : Proposition du Pack Premium
- **Downsell** : Proposition du Plateau Apéritif
- **Page de Commande** : Formulaire de commande intégré
- **Page de Remerciement** : Confirmation et instructions
- **Design Responsive** : Optimisé mobile et desktop

## 🚀 Déploiement

Ce site est automatiquement déployé sur GitHub Pages via GitHub Actions.

**URL du site** : https://hounsoupeninna-gif.github.io/Dame-samoussa/

## 💻 Développement Local

### Prérequis
- Node.js (v18 ou supérieur)

### Installation

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Construire pour la production
npm run build
```

## 🛠️ Technologies

- **React 19** - Framework UI
- **TypeScript** - Typage statique
- **Vite** - Build tool ultra-rapide
- **Tailwind CSS** - Framework CSS (via CDN)
- **GitHub Actions** - CI/CD automatique
